Design Direction · Flight Checks

Flight Deck

A native-feeling redesign in Apple's design language: sidebar navigation like a macOS app, SF Pro system typography, Apple's semantic color system in light and dark, and grouped-inset settings. Quiet surfaces, one blue accent, and the numbers doing the talking.

Three rules the whole UI follows

Deference to content

The chrome is grey and quiet. Color appears only where it means something: blue for actions and selection, green for "fits your balance", red for errors. Never decorative.

Depth through layers, not lines

White cards float on a soft grey ground with faint shadows — the macOS window model. Hairline separators replace table borders. Nothing is boxed twice.

Clarity of hierarchy

Every screen opens with a large title and a one-line summary. Data uses tabular numerals; the ranking metric (¢/pt) is the visually heaviest thing in each row.

Color

Apple's semantic palette, tokenized as CSS variables. Every color has a light and dark value; components only ever reference the token. The accent is Apple system blue — the single brand color.

Tinted fills (12–18% alpha of the semantic color) back chips and secondary buttons — the iOS "tinted button" pattern — so color never arrives at full strength except on the primary action.

Typography

SF Pro via the system font stack — the app renders in the real Apple face on your Mac with zero font payload. Negative tracking on titles, tabular numerals on every figure.

Buttons & controls

Four button levels, one accent. These are the real proposed components — hover and press them.

Filled = the one primary action per screen. Tinted = secondary actions. Plain (grey) = neutral. Red tint = destructive. Quiet = inline links. Small size (below) for row-level actions.

Settings — grouped inset lists

The settings form becomes the macOS System Settings pattern: captioned groups of inset rows, human labels instead of raw keys (thresholds.economy → "Economy alert threshold"), values editable in place, toggles for booleans.

Motion & detail

  • Press states scale buttons to 97% — the iOS spring feel; hover tints rows with the 12% accent wash.
  • Tab switches cross-fade content in 150 ms; no slides, no bounces. Reduced-motion turns it all off.
  • Scanning state: the primary button shows an inline spinner and the Runs row pulses its blue "running" chip.
  • Error banner becomes a floating rounded toast at top center — red tint, dismiss on click — instead of a full-width red bar.
  • Everything keyboard-focusable draws the 2px blue focus ring.
